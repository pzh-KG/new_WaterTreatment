一、134：阅读开始前输入超限，不是模型读完后抽取失败

失败记录：理解阶段提示文本 1,599,608 UTF-8 字节，超过 900,000 字节上限；实际模型调用为 0，无阅读档案或候选 JSON。

预防：源文件和完整解析结果保持不变；模型初始交付去除重复运输/定位元数据，保留所有块、原文、顺序、表格坐标、公式、图片变换和异常。完整原始元数据仍可工具回查。准备阶段同时预检理解和后续首审的预算，不能先付出阅读成本才发现无法审查。
本次离线重建的阅读上下文为 389,771 字节；包含预留量的理解预算 462,962、首审预算 725,387，均通过上限检查。此结果只证明可进入处理，不证明已完成阅读或科学抽取。

二、135：前两阶段完成，但首审预算不足；同时存在系统身份字段错填
原运行：20261116T185820-6fa6650096a9。
理解调用耗时 1,620.172 秒，抽取调用耗时 3,341.890 秒，合计约 82.7 分钟。265 条观测已保存。首审尚未调用，控制器报“no space for a bound candidate view within the reserved prompt budget”。
旧阅读上下文约 902,133 字节；原流程没有为首审必须携带的候选视图和反馈留出足够空间。

预防：前置检查全过程固定输入预算；系统身份由控制器与来源清单绑定，不交由模型自由决定。发现身份差异应明确区分系统元数据修正和科学数据修订。

三、139：局部修订后审查范围和完成协议不够明确
原运行：20261117T012606-3cb045887920，已有 160 条观测。
原运行完成了理解、抽取、首审和修订，但修订后仍提交约 829,985 字节的整稿审查，最终在剩余时间内未完成。
后续 20261117T073329-f8423e2694b6 已返回审查回答，但控制器因 Word 原生表格的来源交付要求不匹配拒绝收录。历史要求把没有物理页图的原生表格视同必须截图查看的图片；完整结构读取与图像查看不能混为一谈。
最近一次补审 20261117T081645-c0a39d73152c 耗时 600.688 秒超时，没有最终回答。冻结的补审来源新增要求为空，但模型仍多次打开原文图页。工具交付完成并不代表审查结论已经提交，不能据此标为审查通过。
预防：继承可认证的完整首审，只审查改动字段、受影响关系及来源；区分原生 Word 表格结构读取与 PDF/图片查看；已经满足的来源要求保存可重放回执；只剩逐项结论提交时使用明确的受限补审任务，不重新启动全文浏览。
恢复必须保留原审查疑点和限制，不得用“已读过”代替科学判断。超时仅保存已有进度；再次继续也必须继承已消耗时间和调用次数，不能通过新建 run 无限重置预算。
补审后仍可能存在独立的阅读覆盖档案缺项；这些缺项要单独处理，不能把 XML 空容器、未读内容和作者未报告视为同一状态。

四、后续通用约束
1. 开始前检查来源完整性、输入体积和后续审查预留空间；超限则给出明确分段阅读方案，禁止截掉正文或 SI。
2. 文献系统编号、来源归属和版本身份由注册清单控制；模型输出身份异常尽早发现，禁止悄悄跨文献复用。
3. 理解、抽取、首审、修订、局部复审、覆盖补正分别保存完成凭据；从未完成阶段继续。
4. 查询和来源读取回执按来源哈希、候选版本和审查范围绑定。必要回查仍允许，重复读取不能被当作质量保证。
5. 只有完整、来源可验证的审查回答才构成模型审查完成。超时、局部读取完成、有 JSON、机器错误为零均不能替代它。
6. 每种失败增加通用合成测试，验证拒绝篡改、保留旧版本、预算不重置和不重抽；生产逻辑不写死论文序号或论文答案。
