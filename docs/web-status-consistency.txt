网页状态、统计与总览跳转

统一统计对象
总览、文献库和数据与入库使用同一份工作区快照，按已登记文献的当前结果去重。
“已有结果”包含未完成候选；“自动处理完成”仅包含当前版本通过准入检查的文献。二者不应混作一个数量。
同文献多个结果版本保留。默认列表按篇展示当前版本，开启历史版本后按结果版本数展示。
“最新版本已入库”只计当前版本已成功同步到图谱的文献。更早的图谱版本不会充当当前版本已入库。
“已人工抽查”仅计当前版本有实际核查记录的文献。加入抽查清单并不等于已做核查；局部核查也不等于整篇科学验证。

文献状态与运行历史
当前结果状态和最新运行尝试分开显示。已有完成结果后再次尝试失败，不会抹掉旧的有效结果。
旧任务的原始失败或中断状态保持不变；当同文献出现更晚、通过准入检查的当前版本时，任务页显示“后续已修复完成”及新结果入口。
失败任务的耗时和日志仍描述那次实际运行，不挪用后续任务的耗时。
仅准备计划、修改程序或保存待审 JSON，不能将文献标为已审查完成。

桌面端与命令行续处理
网页检测登记在当前数据根目录的终态产物变化，一次性刷新本地结果索引并验证准入。
常规轮询查看文件元数据和索引摘要，不反复读取所有论文原文；有新终态结果时才执行必要的来源证明检查。
索引同步期间保留原结果，并显示同步状态。同步失败不会自动升级完成状态，也不会每轮无条件重试。
界面按工作区版本变化刷新，不再只盯着旧网页任务的状态是否改变。

总览跳转
已登记文献 -> 文献库，清除先前筛选。
自动处理完成 -> 文献库，筛选自动处理完成。
最新版本已入库 -> 数据与入库，筛选当前已入库结果。
已人工抽查 -> 人工抽查，展示已有实际核查记录的当前结果。
筛选条件写入网址，刷新和前进/后退时可恢复；卡片与对应列表按同一统计口径显示。

边界
这些改动管理本地状态、索引和展示，不修改科研 JSON，不自动发起抽取、模型问答或 Neo4j 写入。
自动审查完成仍不等同于人工验证或科学正确性已获保证。
